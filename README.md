# Portfolio SAP – Raphaël LEGROS

Bienvenue sur mon portfolio de livrables réalisés dans le cadre de ma **Formation de Consultant ERP SAP** dispensée par **SproClub**, avec une spécialisation **SD/MM**.

Ce dépôt a pour but de présenter des exemples concrets de mon travail à d'éventuels recruteurs ou clients : veille sectorielle, formation utilisateur, spécifications fonctionnelles, migration de données et résolution d'incidents.

> ℹ️ Les livrables font référence à **AGRIVAL**, une entreprise fictive créée à des fins pédagogiques dans le cadre de la formation.
